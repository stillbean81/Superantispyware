## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Installer stops at "preparing" | Close other installers, reboot, then run the setup again. |
| Scan takes very long | Switch to a Quick or Critical Point scan, or limit custom scan targets. |
| Real time protection will not enable | Confirm the service is running in Windows Services, then restart the app. |
| Definitions fail to update | Check firewall rules, or download the offline definition package manually. |
| App window is blank after install | Update your graphics driver and relaunch from the Start menu. |
| Quarantine items return after restore | Re-run a full scan, some items reinstall from a parent process. |
